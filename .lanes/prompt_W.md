# Workstream: worldbank (directory `worldbank/`, disk budget 8 GB)

Goal: build and publish the first leakage-controlled join of World Bank Project Appraisal Documents (the proposal text) to IEG outcome ratings (the independent outcome), and run a text baseline.

## Verified facts (2026-09-15, main session)
- Documents & Reports API: `GET https://search.worldbank.org/api/v3/wds?format=json&rows=1&docty_exact=Project%20Appraisal%20Document` returns total 6,991; `Implementation Completion Report Review` 7,815; `Implementation Completion and Results Report` 8,603. Records carry `projectid` (P-number), `docdt`, `abstracts`, `pdfurl`, `txturl` (plain-text version), `display_title`, `guid`, `url`. Paginate with `rows` and `os` (offset); read https://documents.worldbank.org/en/publication/documents-reports/api for parameters.
- Projects API: `GET https://search.worldbank.org/api/v3/projects?format=json&rows=1` returns total 28,113 with fields including id, countryshortname, boardapprovaldate, closingdate, totalamt, lendprojectcost, regionname, borrower, impagency, project_name, sector/theme fields.
- IEG ratings dataset: https://financesone.worldbank.org/ieg-world-bank-project-performance-ratings/DS00053 (12,598 rows x 21 columns, CC BY 4.0, evaluations from FY1974). The page is a JS app; find the bulk download or API link (try the "Bulk download" / "API Service" affordances, the Socrata mirror https://finances.worldbank.org/resource/mmr8-7eg3.json and https://finances.worldbank.org/api/views/mmr8-7eg3/rows.csv?accessType=DOWNLOAD, and the financesone API endpoints visible in the page's network calls if you can read the page source). Record the exact 21 column names and the rating scales you observe. If no machine-readable path works, say so and stop that branch; do not hand-type ratings.

## Build
1. Pull all PAD, ICR, and ICRR records (metadata) with pagination; save as parquet under `data/raw/worldbank/wds/`. Pull all projects metadata. Pull the IEG ratings table.
2. Join on P-number. Keep, per project, the earliest PAD whose `docdt` is on or before the board approval date + 30 days (record the count that fail this test: additional-financing PADs and restructuring papers share the P-number and postdate approval, which is the leakage to exclude). Record the funnel: projects with ratings; with any PAD; with a qualifying PAD; with a downloadable txturl.
3. Download the qualifying PAD plain text (`txturl`) into `data/raw/worldbank/pad_text/` (gitignored), with sha256 and byte size recorded in the release table; cap at 8 GB total; if the corpus exceeds it, sample by stratified board-approval year and say so. Be polite: 4 concurrent requests max, retry with backoff.
4. Release table `worldbank/results/pad_ieg_join.csv`: projectid, project_name, country, region, sector, board approval date, closing date (planned, from the PAD-era metadata if available; and actual), commitment amounts, PAD guid, PAD docdt, PAD txturl, text sha256, text bytes, and every IEG rating column (outcome, bank performance, borrower performance, risk to development outcome, M&E quality, ICR quality, plus the Bank's own ICR ratings if the dataset carries them), evaluation fiscal year, evaluation type (ICRR vs PPAR). Also a derived `schedule_slip_days` = actual closing minus planned closing where both exist.
5. Baseline models on outcome >= Moderately Satisfactory (define from the observed scale and report the scale): (a) base rate; (b) country x approval-decade x sector cell means with shrinkage; (c) logistic regression on TF-IDF of the PAD text (unigrams+bigrams, min_df 5) plus the structured fields; (d) text only. Forward-chained: train on approval years up to 2005, validate 2006 to 2010, test 2011 onward (adjust cut points to give at least 800 test rows; report). Report AUC, Brier, BSS vs base rate and vs the cell baseline, calibration table, and the same metrics residualised: AUC within country (mean of per-country AUC weighted by n) to show skill beyond the country effect.
6. Also report the Bank-vs-IEG disagreement rate (ICR self-rating vs ICRR rating) by year, since that is a known quantity the scoreboard would show.
